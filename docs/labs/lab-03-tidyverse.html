24  Laboratorio 3 · Guía rápida de tidyverse

Este laboratorio funciona como referencia rápida durante los ejercicios.

24.1 Pipe

datos |>
  operacion_1() |>
  operacion_2()

Léelo de izquierda a derecha: toma estos datos y luego…

24.2 select()

ventas |>
  select(fecha, region, valor_venta)

24.3 filter()

ventas |>
  filter(region == "Caribe", valor_venta > 200000)

24.4 mutate()

ventas |>
  mutate(
    tiene_descuento = descuento > 0
  )

24.5 arrange()

ventas |>
  arrange(desc(valor_venta))

24.6 group_by() + summarise()

ventas |>
  group_by(region) |>
  summarise(
    ventas = sum(valor_venta, na.rm = TRUE),
    clientes = n_distinct(id_cliente),
    .groups = "drop"
  )

24.7 count()

ventas |>
  count(canal, sort = TRUE)

24.8 distinct()

ventas |>
  distinct(id_cliente)

24.9 Joins

Cuando dos tablas comparten una llave:

ventas |>
  left_join(clientes, by = "id_cliente")

Antes del join revisa la unicidad de la llave para evitar multiplicar registros accidentalmente.

24.10 Pivot

datos |>
  pivot_longer(
    cols = starts_with("venta_"),
    names_to = "periodo",
    values_to = "venta"
  )

pivot_longer() y pivot_wider() cambian la forma de una tabla; no deberían cambiar el significado de las observaciones.

24.11 Pro Tip

Necesito… Función
columnas select()
filas filter()
crear variable mutate()
ordenar arrange()
agrupar group_by()
indicador summarise()
frecuencia count()
únicos distinct()
combinar tablas *_join()
cambiar forma pivot_*()
