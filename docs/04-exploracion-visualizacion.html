10  Exploración y visualización de datos

10.1 Propósito

El análisis exploratorio de datos (EDA) busca comprender la estructura de una base antes de formular conclusiones. Exploraremos distribuciones, segmentos, valores atípicos y relaciones utilizando resúmenes y visualizaciones.

NotaRuta de clase · Sábado

Este capítulo se trabaja como laboratorio. La prioridad es producir pocas visualizaciones con interpretación, no una galería de gráficos.

10.2 Una visualización debe responder una pregunta

Antes de escribir ggplot(), formula la pregunta:

¿Qué comparación quiero facilitar?

Ejemplos:

  • ¿qué regiones concentran las ventas?
  • ¿cómo se distribuye el valor de las transacciones?
  • ¿qué canales presentan mayor dispersión?
  • ¿cómo cambia el descuento entre categorías?

10.3 Ventas por región

Primero construimos la tabla que alimentará el gráfico:

ventas_region <- ventas |>
  filter(estado == "Completada") |>
  group_by(region) |>
  summarise(
    ventas = sum(valor_venta, na.rm = TRUE),
    .groups = "drop"
  )

Después visualizamos:

library(ggplot2)

ggplot(
  ventas_region,
  aes(x = reorder(region, ventas), y = ventas)
) +
  geom_col() +
  coord_flip() +
  labs(
    title = "Ventas por región",
    x = NULL,
    y = "Ventas"
  )

La gráfica facilita una comparación que ya existe en la tabla. No reemplaza el razonamiento.

10.4 Distribución de una variable

ggplot(
  ventas |> filter(estado == "Completada"),
  aes(x = valor_venta)
) +
  geom_histogram(bins = 30) +
  labs(
    title = "Distribución del valor de las transacciones",
    x = "Valor de venta",
    y = "Frecuencia"
  )

Pregunta:

  • ¿la distribución es simétrica?
  • ¿existen colas largas?
  • ¿el promedio representa bien una transacción típica?
  • ¿aparecen observaciones que merecen inspección?

10.5 Comparar distribuciones

ggplot(
  ventas |> filter(estado == "Completada"),
  aes(x = canal, y = valor_venta)
) +
  geom_boxplot() +
  labs(
    title = "Valor de transacción por canal",
    x = NULL,
    y = "Valor de venta"
  )

Un boxplot permite comparar posición, dispersión y valores extremos entre grupos.

Advertencia

Un outlier es una observación que merece atención, no automáticamente un error.

10.6 Relación entre variables

Podemos explorar si los descuentos y el valor de venta presentan algún patrón:

ggplot(
  ventas |> filter(estado == "Completada"),
  aes(x = descuento, y = valor_venta)
) +
  geom_point(alpha = 0.35) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    title = "Descuento y valor de venta",
    x = "Descuento",
    y = "Valor de venta"
  )

Una asociación visual no demuestra causalidad.

10.7 La estructura de una interpretación

Para cada visualización escribe tres elementos:

10.7.1 Hallazgo

¿Qué patrón relevante observas?

10.7.2 Evidencia

¿Qué comparación o magnitud sustenta el hallazgo?

10.7.3 Implicación

¿Por qué podría importarle a una persona que toma decisiones?

Ejemplo:

Hallazgo: la región A concentra las ventas, pero el canal web tiene menor ticket promedio.
Evidencia: …
Implicación: conviene investigar si la estrategia digital está impulsando volumen a costa del valor por operación.

10.8 Visualizaciones que evitaremos

Evita gráficos cuando:

  • una cifra única comunica mejor;
  • existen demasiadas categorías sin jerarquía;
  • la escala exagera diferencias;
  • el gráfico 3D agrega decoración y no información;
  • se usan colores sin propósito;
  • la conclusión depende de una comparación difícil de percibir.

10.9 Introducción al análisis de texto

Los datos empresariales no son únicamente numéricos. Comentarios de clientes, encuestas y tickets contienen información no estructurada.

Los comentarios que utilizaremos están en data/satisfaccion.csv, en la variable comentario. Primero cargamos ese archivo y luego podemos tokenizar los textos para estudiar términos frecuentes:

library(tidytext)

# Los comentarios están en satisfaccion.csv
comentarios <- readr::read_csv("data/satisfaccion.csv") |>
  select(id_encuesta, id_cliente, calificacion, nps, comentario)

comentarios |>
  unnest_tokens(palabra, comentario) |>
  count(palabra, sort = TRUE)

La frecuencia de palabras es un punto de partida, no una interpretación completa del lenguaje.

10.10 Taller de EDA

Construye al menos cuatro visualizaciones:

  1. una comparación entre categorías;
  2. una distribución;
  3. una comparación entre grupos;
  4. una relación entre dos variables.

Para cada una redacta hallazgo + evidencia + implicación.

Después selecciona únicamente las dos que llevarías a una reunión gerencial.

10.11 Analytics + IA

Entrega a una IA una descripción estadística o los resultados de una tabla —sin datos sensibles— y solicita tres hipótesis.

Después clasifica cada respuesta:

  • observación sustentada;
  • interpretación plausible;
  • especulación;
  • afirmación causal no demostrada.

Esta clasificación es parte del trabajo analítico.

10.12 Producto del primer fin de semana

Al terminar el bloque, cada equipo debe contar con:

  • pregunta de negocio;
  • script reproducible;
  • diagnóstico inicial de calidad;
  • tabla de indicadores;
  • análisis exploratorio;
  • visualizaciones comentadas;
  • tres hallazgos preliminares;
  • preguntas que todavía no puede responder.

El segundo fin de semana comenzará precisamente con esas limitaciones.
