8.2 Preparar la sesión

Copia este bloque al inicio de tu script. Así la sesión puede ejecutarse de manera independiente.

8.4 Manipulación · pregunta → código → tabla → interpretación

8.4.1 Demo docente

¿Qué regiones concentran las ventas completadas?

ventas_region <- ventas |>
  filter(estado == "Completada") |>
  group_by(region) |>
  summarise(
    ventas = sum(valor_venta, na.rm = TRUE),
    transacciones = n_distinct(id_venta),
    clientes = n_distinct(id_cliente),
    .groups = "drop"
  ) |>
  mutate(ticket_promedio = ventas / transacciones) |>
  arrange(desc(ventas))

ventas_region

Checkpoint: antes una fila era una transacción; ahora una fila es una región.

8.5 EDA · primero tabla, después gráfico

ggplot(ventas_region, aes(x = reorder(region, ventas), y = ventas)) +
  geom_col() + coord_flip() +
  labs(title = "Ventas completadas por región", x = NULL, y = "Ventas")

Discusión: ¿el gráfico responde la pregunta?, ¿qué denominador falta?, ¿qué conclusión sería excesiva?

8.7 Taller evaluable

Cada grupo elige una combinación de dimensión/variable categórica + KPI + experiencia del cliente y entrega:

  1. tabla reproducible;
  2. dos visualizaciones;
  3. una exploración textual;
  4. dos hallazgos en formato evidencia → significado → implicación;
  5. una hipótesis que todavía no puede afirmarse.
