14  Taller evaluable · InsureCO

Producto: un análisis exploratorio reproducible y una nota ejecutiva de máximo dos páginas. El propósito no es demostrar fórmulas: es convertir resultados descriptivos en evidencia útil sin exceder lo que los datos permiten afirmar.

14.1 Caso

InsureCO dispone de 1.338 registros sobre personas aseguradas. La organización quiere comprender qué características describen a su cartera y qué relaciones merecen una investigación posterior.

Una fila representa una persona asegurada.

Variable Significado Tipo
age edad en años cuantitativa
sex sexo registrado cualitativa
bmi índice de masa corporal cuantitativa
children número de hijos/dependientes cuantitativa discreta
smoker hábito de consumo de cigarrillos (yes/no) cualitativa
region región de residencia cualitativa
charges costo individual observado de la póliza cuantitativa
Nota

Los datos se utilizan con fines pedagógicos. charges es un costo observado; no debe interpretarse automáticamente como tarifa recomendada, riesgo causal o decisión de aseguramiento.

14.2 Descargar los datos

Descargar insureco.csv

Guárdalo en una carpeta fácil de identificar. No cambies los nombres de las variables antes de ejecutar el diagnóstico inicial.

14.3 Preparar el análisis en RStudio

# El selector permite ubicar el archivo sin escribir una ruta manual.
insureco <- read.csv(file.choose(), stringsAsFactors = FALSE)

dim(insureco)
names(insureco)
str(insureco)
head(insureco)
colSums(is.na(insureco))

Checkpoint: antes de calcular, confirma que hay 1.338 filas, 7 variables y explica qué representa una fila.

14.4 Pregunta 1 · Describir la edad

Describe la edad de las personas aseguradas mediante medidas de tendencia central, posición y dispersión. Decide qué combinación comunicarías a la gerencia y por qué.

14.4.1 Código de partida

moda <- function(x) {
  frecuencias <- table(x)
  as.numeric(names(frecuencias)[frecuencias == max(frecuencias)])
}

edad <- insureco$age

resumen_edad <- c(
  n = sum(!is.na(edad)),
  media = mean(edad, na.rm = TRUE),
  mediana = median(edad, na.rm = TRUE),
  moda = moda(edad)[1],
  minimo = min(edad, na.rm = TRUE),
  maximo = max(edad, na.rm = TRUE),
  rango = diff(range(edad, na.rm = TRUE)),
  p25 = quantile(edad, .25, na.rm = TRUE),
  p75 = quantile(edad, .75, na.rm = TRUE),
  IQR = IQR(edad, na.rm = TRUE),
  varianza = var(edad, na.rm = TRUE),
  desviacion = sd(edad, na.rm = TRUE),
  CV = sd(edad, na.rm = TRUE) / mean(edad, na.rm = TRUE)
)

round(resumen_edad, 2)

par(mfrow = c(1, 2))
hist(edad, col = "#9ecae1", border = "white",
     main = "Distribución de edad", xlab = "Edad")
boxplot(edad, horizontal = TRUE, col = "#99d8c9",
        main = "Edad y posibles atípicos")
par(mfrow = c(1, 1))

14.4.2 Debes responder

  1. ¿Qué dicen media, mediana y moda? ¿Cuentan la misma historia?
  2. ¿Cuál es la amplitud total y dónde se concentra el 50 % central?
  3. ¿Qué medida de centro y qué medida de dispersión comunicarías?
  4. ¿La gráfica cambia o matiza tu interpretación numérica?

14.5 Pregunta 2 · Fumar y región de residencia

Caracteriza la relación que puede existir entre el hábito de fumar y la región mediante una tabla de contingencia. No te limites a los conteos: selecciona el porcentaje cuyo denominador responda la pregunta.

tabla <- table(
  Region = insureco$region,
  Fumador = insureco$smoker
)

tabla

# Cada fila suma 100 %: dentro de cada región,
# ¿qué proporción fuma y qué proporción no fuma?
porcentaje_region <- prop.table(tabla, margin = 1) * 100
round(porcentaje_region, 1)

barplot(t(porcentaje_region),
        beside = FALSE,
        col = c("#9ecae1", "#fdae6b"),
        legend.text = TRUE,
        xlab = "Región", ylab = "Porcentaje dentro de la región",
        main = "Hábito de fumar por región")

14.5.1 Debes responder

  1. ¿Cuál región tiene el mayor número de personas fumadoras?
  2. ¿Cuál tiene la mayor proporción de personas fumadoras?
  3. ¿Por qué comparar solo conteos puede ser engañoso?
  4. ¿La tabla permite afirmar que la región causa el hábito de fumar? Justifica.
Tip

Usa margin = 1 si la pregunta es “dentro de cada región, ¿qué porcentaje fuma?”. Usa margin = 2 si la pregunta condiciona por la categoría de fumador. El denominador cambia la historia.

14.6 Pregunta 3 · IMC y costo de la póliza

Explora la relación entre bmi y charges con un diagrama de dispersión y los coeficientes de Pearson y Spearman.

plot(insureco$bmi, insureco$charges,
     pch = 19, col = rgb(14/255, 90/255, 156/255, .35),
     xlab = "Índice de masa corporal (BMI)",
     ylab = "Costo observado de la póliza",
     main = "BMI y costo")
abline(lm(charges ~ bmi, data = insureco),
       col = "#b91c1c", lwd = 2)

cor(insureco$bmi, insureco$charges,
    method = "pearson", use = "complete.obs")
cor(insureco$bmi, insureco$charges,
    method = "spearman", use = "complete.obs")

14.6.1 Debes responder

  1. ¿Cuál es el sentido y la fortaleza aparente de la asociación?
  2. ¿La nube muestra subgrupos, asimetría o valores extremos?
  3. ¿Qué variables disponibles podrían estar ocultando diferencias relevantes?
  4. Completa: “Con estos resultados podemos afirmar ; todavía no podemos afirmar ”.

14.7 Una media global puede ocultar el problema

La relación entre IMC y costo puede comportarse distinto entre personas fumadoras y no fumadoras. Compara antes de concluir.

aggregate(charges ~ smoker, data = insureco,
          FUN = function(x) c(
            n = length(x),
            media = mean(x),
            mediana = median(x),
            sd = sd(x),
            p90 = quantile(x, .90)
          ))

boxplot(charges ~ smoker, data = insureco,
        col = c("#9ecae1", "#fdae6b"),
        xlab = "¿Fuma?", ylab = "Costo observado",
        main = "Costo por hábito de fumar")

by(insureco[, c("bmi", "charges")],
   insureco$smoker,
   function(d) cor(d$bmi, d$charges))

Esta extensión no pide explicar causalmente el costo. Busca reconocer que una estadística agregada puede mezclar grupos con comportamientos diferentes.

14.8 Entregable

Entrega un PDF de máximo dos páginas y el script .R que lo reproduce desde una sesión limpia.

El PDF debe contener:

  1. título, autor y pregunta de negocio;
  2. una tabla compacta para la edad;
  3. una tabla cruzada con porcentajes claramente denominados;
  4. dos visualizaciones: una obligatoria para bmi–charges y otra elegida por ti;
  5. tres hallazgos escritos como evidencia → significado → implicación;
  6. una hipótesis razonable que requiera análisis adicional;
  7. una limitación y una declaración breve del uso de IA.

14.8.1 Plantilla para cada hallazgo

Evidencia: [resultado numérico o patrón visible].
Significado: [qué describe en esta cartera].
Implicación: [qué pregunta, revisión o decisión podría orientar].
Límite: [qué no demuestra].

14.10 Uso permitido de IA

Puedes pedir ayuda para explicar un error, comentar código, proponer verificaciones o cuestionar una interpretación. No debes entregar una conclusión que no puedas conectar con una salida reproducible.

Prompt recomendado:

CONTEXTO
Analizo 1.338 registros de InsureCO. Una fila representa una persona asegurada. Las variables disponibles son age, sex, bmi, children, smoker, region y charges.

TAREA
Audita mi interpretación. Separa: (1) observaciones respaldadas por las salidas, (2) hipótesis plausibles y (3) afirmaciones causales que estos datos no permiten.

FORMATO
Tabla: frase original | clasificación | evidencia requerida | redacción prudente.

RESTRICCIONES
No inventes resultados ni variables. Si falta una salida, solicítala.
