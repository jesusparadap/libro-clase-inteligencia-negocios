13  Calidad de datos y ETL: de raw a analysis-ready

13.1 Propósito

El flujo es:

raw → diagnóstico → reglas → clean → validación → analysis-ready

Nota

Primero diagnosticamos. Después limpiamos. No se corrige lo que todavía no entendemos.

13.2 Carga

library(tidyverse)
library(janitor)
library(skimr)
ventas <- read_csv("data/ventas.csv") |> clean_names()
clientes <- read_csv("data/clientes.csv") |> clean_names()
productos <- read_csv("data/productos.csv") |> clean_names()
satisfaccion <- read_csv("data/satisfaccion.csv") |> clean_names()

13.3 Pregunta cero: granularidad

Tabla Una fila representa
ventas transacción
clientes cliente
productos producto
satisfacción respuesta de encuesta

13.4 Diagnóstico general

skim(ventas)

Busca tipos, faltantes, valores únicos, rangos y distribuciones sospechosas.

13.5 Zoom: categorías

ventas |> count(canal,sort=TRUE)
clientes |> count(ciudad,sort=TRUE)

Las categorías inconsistentes son peligrosas porque pueden producir KPI incorrectos sin generar error.

13.6 Zoom: duplicados

ventas |> count(id_venta) |> filter(n>1)

Antes de eliminar: ¿duplicado exacto, repetición válida o llave mal definida?

13.7 Zoom: faltantes

clientes |> summarise(across(everything(), ~sum(is.na(.) | .=="")))

NA no equivale automáticamente a cero.

13.8 Zoom: reglas y rangos

ventas |> filter(cantidad<=0 | descuento<0 | descuento>1)

Un valor imposible depende de una regla de negocio. Si no está documentada, se valida antes de corregir.

13.9 Outliers

Secuencia: identificar fila → mirar contexto → evaluar plausibilidad → decidir → documentar.

13.10 Una corrección, una verificación

ventas_clean <- ventas |>
  mutate(canal=str_to_title(str_trim(canal)))
ventas_clean |> count(canal)

13.11 Nunca sobrescribas raw

data/raw/ventas.csv
data/clean/ventas_clean.csv

13.12 Integridad y joins

Antes:

clientes |> count(id_cliente) |> filter(n>1)
productos |> count(id_producto) |> filter(n>1)

Huérfanos:

ventas_clean |> anti_join(clientes,by="id_cliente")

Solo después integra. Consulta Cuando un join multiplica filas.
